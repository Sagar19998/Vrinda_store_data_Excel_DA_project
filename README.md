## Vrinda_store_data_Excel_DA_project:

### In this Excel Data Analysis project, I imported the data from Kaggle into an Excel sheet, cleaned the data, and attempted to answer the following questions:
Questions

1} Compare the sales and orders using a single chart

2} Which month got the highest sales and orders?

3} Who purchased more- men or women in 2022?

4} What are the different order statuses in 2022?

5} List the top 10 states contributing to the sales.

6}  Relation between age and gender based on the number of orders

7} Which channel is contributing to the maximum sales?

8} Highest selling category?
